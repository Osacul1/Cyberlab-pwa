PRÁTICA NO APP

🧪 Laboratório

Tudo roda no seu celular, sem atacar ninguém. Aqui você aprende fazendo.

1. Dissecador de URL

Cole uma URL e veja cada parte. Ler URLs é a base de AppSec.

2. Base64 e SHA-256

Base64 é só uma codificação: qualquer um desfaz. SHA-256 é um hash: não dá para desfazer.

3. Ache a vulnerabilidade

Leia o código, escolha o problema e veja a explicação. Cada acerto novo vale 10 XP.

SÓ COM O CELULAR

📱 Praticar no celular

Dá para aprender e praticar bastante só com o celular. Tudo abaixo é legal: são laboratórios feitos para treino. Os planos gratuitos podem mudar, então confira no site.

1. Terminal Linux no celular (Termux)

O Termux é um terminal Linux para Android. Ele conecta com a fase 3 da trilha (Linux e terminal).

  1. Instale o Termux pelo F-Droid (a versão da Play Store está desatualizada).
  2. Abra e rode pkg update para atualizar.
  3. Rode pkg install openssh. Isso instala o comando ssh, que conecta em outro computador.
  4. Conecte no jogo OverTheWire Bandit: ssh bandit0@bandit.labs.overthewire.org -p 2220. A senha do nível 0 é bandit0.
  5. Cada nível ensina um comando (ls, cat, find...) e dá a senha do próximo. Anote os comandos no Caderno.
Por que isso ajuda: Pentest usa muito terminal. Bandit é um laboratório feito para isso, então é permitido.

2. Laboratórios pelo navegador

TryHackMe

Salas guiadas com máquina virtual no navegador. Bom para começar.

picoCTF

Desafios CTF para iniciantes, com terminal web.

PortSwigger Academy

Teoria de AppSec (XSS, SQLi, IDOR). Leia no celular; alguns labs ficam melhores no PC.

OWASP

Leia o OWASP Top 10: é a base de AppSec.

3. Rotina sugerida

  • 10 min: uma aula do CYBERLAB.
  • 10 min: um nível de Bandit ou uma sala do TryHackMe.
  • 5 min: anotar no Caderno o que aprendeu.
Regra: só pratique em laboratórios feitos para treino ou em sistemas seus. Nunca teste sites de terceiros sem autorização.
PARA O FUTURO

💻 Quando tiver um PC

Você não precisa disso agora. Esta aba mostra o que um computador libera, na ordem que eu recomendo.

  1. VirtualBox: roda um sistema dentro do outro, sem riscos para o seu computador.
  2. Kali Linux ou Ubuntu na máquina virtual: seu ambiente de estudo.
  3. Burp Suite Community: intercepta e altera requisições web. É a ferramenta principal de AppSec e Pentest.
  4. OWASP Juice Shop e DVWA: sites vulneráveis de propósito, que você roda no seu próprio computador (com Docker).
  5. Wireshark e nmap: veem o tráfego da rede e as portas abertas, só na sua rede ou em laboratório.
  6. Git e VS Code: para guardar seus projetos e relatórios no portfólio.
Importante: não instale essas ferramentas em computador de empresa. Use somente alvos seus ou de laboratório.
